Cadence is a TypeScript monorepo organized as a pnpm workspace with Turborepo. Primary apps live under apps/: frontend is a React Router v7 SPA deployed to Cloudflare Workers, backend is a Hono Cloudflare Worker with Drizzle + Neon, mobile is an Expo app that is still behind web/backend, and apps/desktop is a placeholder for a future Tauri app. Shared cross-app code should live in packages/. Frontend and mobile consume typed backend contracts through the workspace package @cadence/backend rather than relative filesystem imports.
