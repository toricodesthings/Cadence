Monorepo conventions: deployable apps live in apps/, shared code belongs in packages/, and cross-app type sharing should use workspace package imports. Frontend conventions: keep route files thin, move reusable logic into app/hooks and app/lib, import Radix only through app/components/primitives, and keep optimistic updates as the mutation contract. Backend conventions: UCURD ordering, DRY shared logic in src/lib, centralized Zod/types in src/types, and Cloudflare Worker runtime compatibility. Use pnpm rather than bun/npm for all repo workflows.
