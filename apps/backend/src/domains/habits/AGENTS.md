# Habits — Agent Instructions

Part of the backend: `apps/backend/AGENTS.md` applies.

## Routes

- **habits** (`/habits`): CRUD; reads include shared routines resolved per caller (`loadHabitsForCaller`); logs are per person (`habit_logs.user_id` = who logged); resolve (streak in the user's zone: due days done back from today; skipped days neutral; only today is grace; in turns mode one resolving log closes the day for everyone, `turnFor` picks the holder from `turns_from`, only the logger or owner can clear; supporters see COMPLETED only and can't log); every read returns `withLiveStreaks` (stored streak while today is done or the latest due day before today is done/skipped, else 0). Steps: `stepStatus` sets the day via `stepDayStatus` (a partial day stays PENDING). Set times: one `time` + `at` per resolve, merged into `timeMarks` via `applyTimeMark` with the routine row locked; a whole-day done takes `likelyOpenTime` (nearest open within 90 min today, the only open one on another day) or is refused naming the open times; a whole-day skip is refused; `times` are sorted, one time becomes `targetTime`; steps and `times` are refused together; moving a time carries its marks on every day and re-derives today; editing steps or times re-derives today across every participant's logs. `/weekly` range view: logs and tags pipelined on the RLS connection, then `projectHabitRange` expands the snapshot outside it; logs per due day from the day before creation (earlier only when logged); a pause hides today onward, never the past.
- **routine sharing** (`/habits/:id/…`, `routine-sharing.route.ts`): `POST /:id/invites` (`together` | `turns` | `cheering`; 409 `MODE_SET` on mode clash), `DELETE /:id/invites`, `GET /:id/people`, `PATCH /:id/mode` (re-anchors turns), `PUT /:id/turns`, `DELETE /:id/members/:userId` (re-anchors turns), `DELETE /:id/members` (stop sharing, clears mode and turns), `POST /:id/cheers` (idempotent per sender/recipient/day).
