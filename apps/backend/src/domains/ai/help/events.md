# Events
- [Events](/events) holds personal events like birthdays and anniversaries. Use Add event to create one, or ask the assistant to add, change or remove one.
- Each event can have an emoji, a reminder on the day, and a start date so it counts the years.
- Whether events repeat every year is set under Personal events in [Calendar & Time](?settings=datetime).
- Holidays for your location come from [Location & Weather](?settings=location).
