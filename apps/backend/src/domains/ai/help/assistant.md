# The assistant
- **Can:** read your tasks, notes, schedule, routines, captures, lists and tags; draft new tasks, changes, note edits, reschedules, subtasks, tags, lists, routine check-ins and capture sorting; explain Cadence and link you to places. A note edit shows exactly what changes first, and a long note can only be added to.
- **Can't (yet):** create or edit routines, repeating tasks, events, sections or reminders; change settings; read images.
- **Approval mode** (the menu under the chat box): Ask first (you approve every change), Auto (changes apply themselves, except permanent deletes, note edits that remove text, and anything touching more than 5 tasks), Full (everything applies, permanent deletes included).
- **Name, voice and more** live in [Cadence Assistant](?settings=assistant): the assistant's name, your nickname, the voice (Secretary, Coach, Minimalist, Companion), emoji, suggestions, adaptive tone, memory and custom instructions.
- How your data is used for AI is under [Intelligence & Privacy](?settings=ai).
