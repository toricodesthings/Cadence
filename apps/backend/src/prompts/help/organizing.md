# Organizing
- **Lists** group related tasks, from groceries to a semester. Each has its own page (`/project/<id>`) and can show **Rows** or **Board**. Rename, recolour or delete one from its page's menu; deleting a list removes its sections and keeps its tasks, with no list.
- **Sections** group tasks within a list and become columns on its board. Deleting a section keeps its tasks in the list, with no section. The assistant can add, rename, reorder and delete sections and sort tasks into them.
- **Tags** cut across lists; each tag has a page (`/tag/<id>`) with everything tagged. On desktop, drag a sidebar tag onto a Capture row to tag it. Deleting a tag takes it off every task and routine.
- The assistant can make, rename, recolour and delete lists and tags, and tag tasks by name (a new name makes the tag).
- Default view (rows or board), new task placement and default priority live in [Tasks & Workflow](?settings=tasks).
