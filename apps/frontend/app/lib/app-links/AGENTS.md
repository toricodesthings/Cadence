# App Links — Agent Instructions

Loaded with the [frontend guide](../../../AGENTS.md); its § numbers are referenced here. Edit here, not there.

- **App links:** a task or routine can save one app (`linkedAppId`, a `@cadence/contracts/app-link` id; never a URL) that its details open with one tap. The catalogue (`lib/app-links/catalog.ts`: label, fixed initials, category, aliases, per-platform routes) is the only list; `platform/app-links.ts` `resolveAppLaunch` picks the route for this device before the tap (iPhone/iPad: the app's scheme; elsewhere the HTTPS destination; desktop is always HTTPS through `openExternalUrl`). Or a typed website (`linkedUrl`, the client clears the other field): `resolveWebsite` re-checks it with `parseWebsite` before it becomes a link and labels it by host (punycode, so look-alikes show), and `AppAnchor` re-checks before the desktop `openExternalUrl`. A route is offered only when `verified` (device-tested, vendor-documented, or the app's long-standing scheme); a new candidate ships `verified: false`, seen only in dev/`VITE_SHOW_UNVERIFIED_APPS=true` builds. `shared/AppPane` is a detail pane like Notes (under the title once an app or site is attached, else just above the task's Details trigger; Fixed blocks show it only when one is attached): collapsed with an app it is the app's row plus an `AppLaunchLink` Open pill (a plain anchor; a native scheme never goes through `window.open`/`ExternalLink`), and opened it is `AppChooser` inline, led by the dashed **Website** option (globe tile; one field starting at `https://`, Open saves and opens, Enter saves); choosing saves, never launches, and collapses; Remove has Undo. Rows rank per visit with `lib/app-links/picker.ts` (current choice, then `@cadence/nlp/app-suggestions` from the title unless `nlpEnabled` is off, then A→Z; typed search is `@cadence/search`); a repeating task's app is written to its series (`getTaskSeriesId`), and Task ⇄ Routine conversion carries it.
