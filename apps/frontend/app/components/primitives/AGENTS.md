# Primitives — Agent Instructions

Loaded with the [frontend guide](../../../AGENTS.md); its § numbers are referenced here. Edit here, not there.

- `app/components/primitives/` (check here before styling a new Radix wrapper; primitives import `cn` from `lib/utils`): `SegmentedControl` (header view switchers, the compact board column chooser in `shared/BoardCanvas`, whose column body pages sideways under the finger via `useColumnSwipe`, neighbours beside it, a spring on release; a chooser wider than its scroller lets horizontal drags scroll it instead of scrubbing, short choices: `size`, per-option `tone`; the chosen fill is a lens on `useLensScrub`), `Select` (`ValueSelect` is it at every size), `SearchSelect` (a `Select` with a search box for long lists: countries, regions, time zones), `SearchField` (the one search box: leading icon, Clear, `loading`, `variant` field|bare, `size` sm|md|lg, `trailing`; `SearchTrigger` is its look as a button that opens search elsewhere; never hand-roll a search `<input>`). Every date field is `shared/DatePicker` (on `MonthCalendar`, which the task schedule surface also uses) and every time field `TimePicker`: native picker on a coarse pointer, custom popover otherwise; never a raw `<input type="date|time">`. `Button` primary is `accent-fill` (lit material: gradient, rim, tinted shadow), as is every solid accent button (orbs, send); indicators stay flat.

- `Dialog` and `AlertDialog` share `primitives/dialog-styles.ts` (themed `surface-dialog` glass, layout, header/footer/title type) and `Button` size `md` actions; consumers set size, layout and padding only, never background, border or shadow, and use `DialogCloseButton` for an inline header close. On a touch phone `DialogContent` is a docked sheet (`DIALOG_SHEET`, pulled closed from anywhere; a `DialogFooter` with its own Cancel hides the corner X; `phoneSheet={false}` for full-screen surfaces like `ImageViewer`), while `AlertDialog` stays an inset action sheet. `ContextMenu`, `DropdownMenu`, `Popover`, `Select` and `Tooltip` share `primitives/menu-styles.ts` (`surface-floating`, menu rows where `MENU_ITEM` owns the icon–label gap so items never add `gap-2`/`mr-2`, `MENU_HOVER`'s neutral wash, `GenericMenu`). Every ⋮ speaks one language: each group opens with `DropdownMenu.Label` (`MENU_LABEL`: small muted caps, no icon, so it never reads as a choice); a view is a full-width `SegmentedControl` in `MENU_SEGMENT`; a sort is `DropdownMenu.CheckItem` rows; on/off is `DropdownMenu.SwitchItem` (or `MENU_TOGGLE_ROW` in Schedule's Popover), never a boxed panel. On touch, menus, selects and popovers grow out of and cover their trigger (`FLOATING_MORPH` = `.morph-surface`, a clip-path from the anchor rect; `fromRadius` sets the trigger's corner, capsules by default on phone), and `DropdownMenu`/`ContextMenu` ignore the opening tap's release (`useOpeningReleaseGuard`); with a mouse they pop in (fade and scale from 95%).
